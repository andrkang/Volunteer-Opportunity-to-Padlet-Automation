VOLUNTEER PADLET AUTOMATION
============================

Choose the folder that matches your computer.


WINDOWS 10 OR 11
----------------

1. Open the "Windows" folder.
2. Double-click "Volunteer Padlet Automation Setup.exe".
3. Follow the installation prompts.
4. Open Volunteer Padlet Automation from the Start menu.

The installer includes Python and all required libraries. You do not need to
install anything else.

This free build is not digitally signed. If Windows displays an
"Unknown publisher" or Microsoft Defender SmartScreen message, confirm that
you received this installer from a trusted source. Select "More info", then
"Run anyway" to continue.


MACOS
-----

1. Open the "macOS" folder.
2. Double-click "Volunteer Padlet Automation.dmg".
3. Drag Volunteer Padlet Automation into the Applications folder shown in the
   installer window.
4. Open it from Applications.

This free build is not signed or notarized. If macOS says it cannot verify the
developer, Control-click (or right-click) the app in Applications, choose
"Open", and then choose "Open" again. You normally only need to do this once.


IMPORTANT
---------

Only use an installer received directly from the project owner or another
trusted source.
